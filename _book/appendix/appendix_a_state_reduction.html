Appendix A — 補論A 持ち越す状態と次元の縮約

この補論は、ルックバック・オプション、転換社債、転換価額修正条項つき転換社債（MSCB）、そして縮約できない経路依存の商品（MBS、TARN）を、一つの問いでそろえて整理する。理論と数式の導出だけを書き、実装コードは載せない。数値の実装と、条件を動かして確かめる画面は、Carmine-Studio の第13章〜第15章と、その計算エンジンである rmql にある。

貫く問いは、次の一つである。

明日からの価値を計算するために、今日までの何を覚えておけばよいか。

覚えておくものが増えると、価値関数の変数の数、すなわち状態の次元が増える。次元が増えると、格子の点の数が指数的に増える。そこで、状態を価格との比に直して次元を減らせないか、減らせないならどう評価するか、が問題になる。

本補論の数値は、読者が追えるように、Carmine-Studio の計算（rmql 0.5.0）で確かめた結果に言及するが、導出そのものは数値例に依存しない。数値例が合うことは、その例で成り立つことを示すだけで、命題の証明ではない。

A.1 マルコフ状態の問いと一次同次性

A.1.1 状態とは何か

時刻 \(t\) の価値が、\(t\) 以降の評価に必要なすべての情報を含む変数 \(X_t\) の関数 \(V(t, X_t)\) で書けるとき、\(X_t\) を状態と呼ぶ。株価 \(S_t\) が幾何ブラウン運動に従い、支払いが満期の株価だけで決まるなら、状態は \(S_t\) の一つだけである。支払いが過去の株価に依存するなら、その依存を運ぶ変数を状態に加えなければならない。

商品 覚えておくもの 状態 縮約
ヨーロピアン・オプション なし \(S\)（行使価格 \(K\) は定数） 比 \(S/K\) の 1 変数
ルックバック（変動ストライク） 監視日までの最小値 \(m\) \((S, m)\) 比 \(z = S/m\) の 1 変数
転換社債（転換価額固定） なし \(S\) 1 変数
MSCB（転換時にリセット） なし（転換する時点の株価で決まる） \(S\) 1 変数
MSCB（転換価額を持ち越す） 現在の転換価額 \(K\) \((S, K)\) 限度がなければ比 \(z = S/K\) の 1 変数
MBS 元本残高と、これまでの金利の動き 残高と金利の履歴 比に直せない
TARN 累積クーポンと、まだ償還されていないか 累積クーポンと生存の印 比に直せない

縮約の可否を決めるのは、状態を現物 \(S\) で割った比が、そのまま次の状態として引き継がれるかである。以下の節で、この判定を一つずつ確かめる。

A.1.2 ヨーロピアン・コールの一次同次性

リスク中立測度の下で、株価を \[ S_T = S\,e^{X}, \qquad X = \Bigl(r - q - \tfrac12\sigma^2\Bigr)T + \sigma W_T \] と書く。ここで \(r\) は金利、\(q\) は配当利回り、\(\sigma\) はボラティリティ、\(W_T\) は標準ブラウン運動である。\(X\) は \(S\) にも \(K\) にも依存しない。行使価格 \(K\) のコールの価値は \[ C(S, K) = e^{-rT}\,\mathbb{E}\bigl[(S e^{X} - K)^+\bigr] = K \cdot e^{-rT}\,\mathbb{E}\bigl[(z\,e^{X} - 1)^+\bigr] = K \cdot v(z), \qquad z = \frac{S}{K} \] となる。ここで \(v(z) = e^{-rT}\,\mathbb{E}[(z e^{X} - 1)^+]\) である。すなわち \(C(\lambda S, \lambda K) = \lambda C(S, K)\) が任意の \(\lambda > 0\) について成り立つ（現物と行使価格について一次同次）。同次性は、乱数 \(X\) の分布が水準 \(S\) に依存しないこと（株価の変動が比例的であること）と、支払いが \((S_T, K)\) について一次同次であること、の二つから来る。この二つのどちらかが崩れると、次元は減らない。

この性質は、価値だけでなく感応度にも及ぶ。たとえばデルタは \[ \frac{\partial C}{\partial S} = v'(z) \] となり、水準によらず比 \(z\) だけで決まる。

A.1.3 縮約の一般形

支払いが状態の組 \((S, Y)\)（\(Y\) は「覚えておくもの」で、\(S\) と同じ単位をもつ）について一次同次、状態の動きが比例的なら、 \[ V(S, Y) = Y\,w\!\left(\frac{S}{Y}\right) \] と書ける。\(Y\) が定数のとき（ヨーロピアン）は上のとおりで、\(Y\) が経路の途中で更新されるとき（ルックバック、MSCB のリセット）は、更新の規則が比 \(z\) だけの写像になっているかを確かめる必要がある。次の A.2 と A.4 でそれを行う。

A.2 ルックバック・オプション

A.2.1 商品

満期 \(T\) までの監視日 \(t_1 < \dots < t_n\) に観測した株価の最小値を \(m\)、最大値を \(M\) とする。変動ストライクと固定ストライクの支払いは、次のとおりである。

種類 コール プット
変動ストライク \(S_T - m\) \(M - S_T\)
固定ストライク \(\max(M - K,\,0)\) \(\max(K - m,\,0)\)

ここで \(m\) と \(M\) は、すでに観測した値（満期までに更新される前の、現在の最小値・最大値）と、将来の監視日の株価を合わせたものを指す。以下では、最小値を使う変動ストライクのコールを代表に取る。最大値を使うプットは対称である。

A.2.2 同次性による縮約

時刻 \(t\) に、これまでの最小値が \(m\)、現物が \(S \ge m\) だとする。将来の支払い \(S_T - \min(m, \text{将来の監視値})\) は、\((S, m)\) について一次同次で、株価の動きは比例的である。したがって、A.1.3 より \[ V(t, S, m) = m\,w(t, z), \qquad z = \frac{S}{m} \ge 1 \] と書ける。状態は \((S, m)\) の 2 変数から、比 \(z \ge 1\) の 1 変数に減る。

A.2.3 監視日の更新式の導出

監視日 \(t_k\) の直前と直後で、価値は、最小値の更新を挟んで接続する。直前の最小値を \(m\)、その日の株価を \(S\) とすると、直後の最小値は \(\min(m, S)\) である。したがって、価値の接続条件は \[ V_{\text{前}}(S, m) = V_{\text{後}}\bigl(S, \min(m, S)\bigr) \] である。比 \(z = S/m\) で書き直す。

\(z \ge 1\) のとき（株価が最小値を下回らない）：最小値は更新されず、\(\min(m, S) = m\) である。 \[ m\,w_{\text{前}}(z) = m\,w_{\text{後}}(z) \quad\Longrightarrow\quad w_{\text{前}}(z) = w_{\text{後}}(z). \]

\(z < 1\) のとき（株価が最小値を下回る）：新しい最小値は \(S\) 自身で、直後の比は \(S/S = 1\) である。 \[ m\,w_{\text{前}}(z) = S\,w_{\text{後}}(1) \quad\Longrightarrow\quad w_{\text{前}}(z) = z\,w_{\text{後}}(1). \]

まとめると、監視日の更新式は \[ w_{\text{前}}(z) = \begin{cases} z\,w_{\text{後}}(1) & (z < 1) \\[2pt] w_{\text{後}}(z) & (z \ge 1) \end{cases} \] である。\(z < 1\) の側に \(z\) を掛ける項があることが要点で、これを落とすと（たとえば \(z < 1\) を単に \(z = 1\) に置き換えるだけにすると）、価値は大きく狂う。この項は、最小値が更新される分の価値の比例的な変化を表す。

最終日 \(T\) の支払いは、変動ストライクのコールなら \(S_T - \min(m, S_T)\) を \(m\) で割った \(\max(z - 1, 0)\) の形で、\(w(T, z) = \max(z - 1, 0)\) である（最終日が監視日であるとき、上の更新式を先に適用する）。

A.2.4 木による数値化

比 \(z\) を対数の格子 \(z = u^{j}\)（\(u = e^{\sigma\sqrt{\Delta t}}\)、\(j\) は整数）に取る。\(j = 0\) が \(z = 1\) である。株価は、標準的な二項木（Cox–Ross–Rubinstein）と同じ確率で上下するので、\(z\) も格子の上を 1 段ずつ動く。監視日の間は通常のバックワード（時間をさかのぼる）計算、監視日には A.2.3 の更新式を格子の各点に適用する。\(z < 1\) の点は、監視日の間にだけ現れる（最小値を更新する監視日が来るまで、最小値は古いままだから）。初期の比 \(z_0 = S_0/m_0\) が格子の点でないときは、隣り合う 2 点の値を線形に補間する。

監視を毎段で行う木は、連続監視（A.2.6）に収束するが、収束は遅く、誤差は段数 \(N\) の \(1/\sqrt{N}\) で減る。理由は、監視が段の上の離散点に限られ、段の間の最小値を取りこぼすことにある。Carmine-Studio 第13章の 13.2 は、この収束を rmql の計算で示している。

A.2.5 固定ストライクの還元

固定ストライクのコールの支払いは \((M_T - K)^+\) である。ここで \(M_T\) は満期までの最大値（観測済みの最大値を含む）である。\(K\) を最大値の初期値の候補に加えて \[ \widetilde M_T = \max(M_T,\,K), \qquad (M_T - K)^+ = \widetilde M_T - K \] と書く。\(\widetilde M_T\) は、最大値の初期値を \(\max(M_0, K)\) に置き換えた最大値である。変動ストライクのプットの支払いは \(\widetilde M_T - S_T\) だから \[ (M_T - K)^+ = \underbrace{\bigl(\widetilde M_T - S_T\bigr)}_{\text{変動ストライクのプット（最大値の初期値 }\max(M_0, K)\text{）}} + S_T - K \] となる。両辺の割引現在価値を取ると、\(\mathbb{E}[e^{-rT} S_T] = S\,e^{-qT}\) だから \[ \text{固定コール} = \text{変動プット}\bigl(\max(M_0, K)\bigr) + S\,e^{-qT} - K\,e^{-rT} \] が得られる。同じ議論で、固定ストライクのプットは、最小値の初期値を \(\min(m_0, K)\) に置き換えた変動ストライクのコールを使って \[ \text{固定プット} = \text{変動コール}\bigl(\min(m_0, K)\bigr) + K\,e^{-rT} - S\,e^{-qT} \] と書ける。この還元は、連続監視にも離散監視にも成り立つ（支払いの恒等式だから、監視の方法に依存しない）。したがって、固定ストライクの価格の式を別に用意する必要はなく、変動ストライクの計算だけで足りる。

A.2.6 連続監視と \(b \to 0\) の極限

最小値を連続に監視すると、変動ストライクのコールに閉じた式がある。ドリフト \(b = r - q\) を使って、現物 \(S\)、現在の最小値 \(m\) のとき \[ c = S e^{-qT}N(a_1) - m e^{-rT}N(a_2) + S e^{-rT}\,\frac{\sigma^2}{2b}\left[\Bigl(\frac{S}{m}\Bigr)^{-2b/\sigma^2} N\!\Bigl(-a_1 + \frac{2b\sqrt T}{\sigma}\Bigr) - e^{bT} N(-a_1)\right] \] である。ここで \[ a_1 = \frac{\ln(S/m) + (b + \sigma^2/2)T}{\sigma\sqrt T}, \qquad a_2 = a_1 - \sigma\sqrt T \] であり、\(N\) は標準正規分布の分布関数である。この式は文献（Goldman, Sosin and Gatto, 1979; Conze and Viswanathan, 1991）の標準の式で、本書では導出を与えない（反射原理を使った最小値の分布から得られる）。この補論の著者は、この式を例の入力で rmql の連続監視の関数と比べ、20.58301（\(S = 100\)、\(m = 90\)、\(r = 3\%\)、\(q = 1\%\)、\(\sigma = 25\%\)、\(T = 1\)）で一致することを確かめた。

\(b \to 0\) の極限の考え方：第 3 項は \(1/b\) に比例する。\(b \to 0\) のとき、角括弧の中は \[ \Bigl(\tfrac{S}{m}\Bigr)^{-2b/\sigma^2}N\!\Bigl(-a_1 + \tfrac{2b\sqrt T}{\sigma}\Bigr) - e^{bT}N(-a_1) \;\longrightarrow\; N(-a_1) - N(-a_1) = 0 \] となるので、第 3 項は \(0/0\) の形である。角括弧の中を \(G(b)\) と書くと、\(G\) は \(b\) について解析的で \(G(0) = 0\) だから、 \[ \lim_{b \to 0}\frac{G(b)}{b} = G'(0) \] で極限が存在する。実装では、\(|b|\) が小さいとき、\(G(b)/b\) を \(b\) のべき級数（3 次まで）に置き換える。式のまま計算すると、丸め誤差が \(\varepsilon/|b|\)（\(\varepsilon\) は機械イプシロン）の大きさで効き、一方、べき級数の打ち切り誤差は \(b^{3}\) の程度だから、両者が釣り合う \(|b|\) を境に使い分けるのが妥当である。価値は \(b = 0\) で連続であって、\(b = 0\) ちょうどだけ式が定義されないのは、式の書き方の問題であり、価値の性質ではない。

A.2.7 離散監視の価値は区分線形である

A.2.4 の木で、時刻 0 の価値は、初期の比 \(z_0\) を挟む 2 点の値の線形補間だから、\(S_0\) の関数として区分線形である。区分線形な関数は、折れ目を除いて 2 階微分が 0 である。したがって、木の価値を自動微分して得る 2 階微分（ガンマ）は 0 になり、連続監視のガンマの近似にはならない。ガンマは、格子の点の値の 2 階差分で求める必要がある（補論Bの B.5 で再び扱う）。

A.3 転換社債

A.3.1 商品と信用リスクの扱い

転換社債（CB）は、債券に、株式への転換権がついたものである。保有者は、転換すれば転換価値 \(\kappa S\)（\(\kappa\) は転換比率）を、しなければクーポンと償還額を受け取る。発行体の信用リスクは、転換されない部分だけにかかる。転換すれば株式を受け取るので、その価値は発行体の信用スプレッドで割り引かれないからである。

A.3.2 Tsiveriotis–Fernandes の枠組み

信用スプレッドを \(s\) とし、価値 \(V\) と、転換に至る確率 \(p\) を、節点ごとに持つ。転換される部分の割引率は \(r\)、されない部分は \(r + s\) だから、節点の割引率は \[ \rho = p\,r + (1 - p)(r + s) = r + (1 - p)\,s \] である。\(p = 1\)（必ず転換される）なら信用スプレッドは効かず、\(p = 0\)（転換されない）なら普通の債券と同じ \(r + s\) で割り引く。

二項木での 1 段のバックワード計算は、価値 \(V\) と確率 \(p\) を同じ重みで戻す。上昇の確率を \(p_u\)、下降を \(p_d\) として \[ V_j \leftarrow \frac{p_d\,V_j}{1 + \rho_j\,\Delta t} + \frac{p_u\,V_{j+1}}{1 + \rho_{j+1}\,\Delta t}, \] \(p\) も同じ重みで戻す（割引率 \(\rho\) は、上の式のとおり、1 段先の節点の \(p\) から作る）。この単純割引の形は、QuantLib の二項木の転換社債のエンジンに合わせたものである。

各節点の時刻では、コール（発行体の償還権）、プット（保有者の償還請求権）、クーポン、転換の調整を順に行う。転換の調整は \[ V \le \kappa S \;\Longrightarrow\; V \leftarrow \kappa S,\; p \leftarrow 1 \] である。つまり、転換価値が継続価値以上なら、転換して \(p = 1\) とする。

A.3.3 極限での確認

信用スプレッドが 0、クーポンなし、ヨーロピアン型の転換で、コールもなければ、価値は \[ V = F\,e^{-rT} + \kappa\,\mathrm{call}\bigl(S,\,F/\kappa\bigr) \] （額面 \(F\) の割引債に、行使価格 \(F/\kappa\) のコールを \(\kappa\) 株分足したもの）である。理由は、満期の支払いが \(\max(F, \kappa S_T) = F + \kappa\,(S_T - F/\kappa)^+\) だからである。この式は、木の実装の検証の基準になる。

A.3.4 デルタとガンマの求め方

転換とコールの判定は節点ごとに切り替わるので、価値は現物について、節点の境界で折れる。そのため、デルタとガンマは、現物をごくわずかにずらした差分ではばらつく。木の最初の 1〜2 段の値から求める Hull の式が使われる。 \[ \Delta \approx \frac{V_{1,u} - V_{1,d}}{S_{1,u} - S_{1,d}}, \qquad \Gamma \approx \frac{\Delta_{\text{上}} - \Delta_{\text{下}}}{\tfrac12\,(S_{2,uu} - S_{2,dd})} \] ここで \(V_{1,u}, V_{1,d}\) は 1 段目の上と下の節点の価値、\(S_{1,u}, S_{1,d}\) はその現物、\(\Delta_{\text{上}}\) と \(\Delta_{\text{下}}\) は 2 段目の上側と下側の隣り合う節点から作ったデルタである。格子の間隔より細かい差分は使わない（B.5 を参照）。

A.4 MSCB（転換価額修正条項つき転換社債）

A.4.1 転換時にリセットする型

転換価額が、転換する時点の株価 \(S\) から \[ K(S) = \min\bigl(K_{\max},\ \max(K_{\min},\ \alpha S)\bigr) \] と決まる型である。\(\alpha\) は 1 以下の値（たとえば 0.9）、\(K_{\min}, K_{\max}\) は下限と上限である。額面 \(F\) を転換して受け取る株式は \(F/K(S)\) 株だから、その価値は \[ \frac{F\,S}{K(S)} = F\,g(S), \qquad g(S) = \max\!\Bigl(\frac{S}{K_{\max}},\ \min\!\Bigl(\frac{S}{K_{\min}},\ \frac{1}{\alpha}\Bigr)\Bigr) \] となる。ここで \(K_{\min} \le K_{\max}\)、\(\alpha \le 1\) とする。転換価値は同時点の株価だけの関数で、持ち越す状態がないから、状態は \(S\) の 1 変数で、固定転換価額の CB（A.3）と同じ木が使える（転換価値の関数だけを差し替える）。

A.4.2 転換価値の 3 本のコールへの分解

\(g\) を、行使価格の違う 3 本のコールの和で書く。\(g - 1\) の正の部分を考える（満期の支払いは \(\max(F, F g) = F + F\,(g - 1)^+\)）。 \[ (g(S) - 1)^+ = \frac{(S - K_{\min})^+}{K_{\min}} - \frac{(S - K_{\min}/\alpha)^+}{K_{\min}} + \frac{(S - K_{\max}/\alpha)^+}{K_{\max}}. \] これは、\(S\) の 4 つの区間で確かめられる。

区間 \((g - 1)^+\) 右辺の 3 項の和
\(S \le K_{\min}\) \(0\) \(0 - 0 + 0 = 0\)
\(K_{\min} < S \le K_{\min}/\alpha\) \(S/K_{\min} - 1\) \((S/K_{\min} - 1) - 0 + 0\)
\(K_{\min}/\alpha < S \le K_{\max}/\alpha\) \(1/\alpha - 1\) \((S/K_{\min} - 1) - (S/K_{\min} - 1/\alpha) + 0 = 1/\alpha - 1\)
\(S > K_{\max}/\alpha\) \(S/K_{\max} - 1\) \((1/\alpha - 1) + (S/K_{\max} - 1/\alpha) = S/K_{\max} - 1\)

（表の最後の 2 行では \(\alpha \le 1\) と \(K_{\min} \le K_{\max}\) を使う。\(S \le K_{\min}\) のとき \(S/K_{\max} - 1/\alpha < 0\) だから、第 3 項は 0 である。）

したがって、ヨーロピアン型で、ゼロクーポン、信用スプレッドなし、コールなしの価値は、行使価格 \(K\) のヨーロピアン・コールの価格 \(\mathrm{call}(K)\) を使って \[ V = F\,e^{-rT} + F\left[\frac{\mathrm{call}(K_{\min})}{K_{\min}} - \frac{\mathrm{call}(K_{\min}/\alpha)}{K_{\min}} + \frac{\mathrm{call}(K_{\max}/\alpha)}{K_{\max}}\right] \] と閉じる（上限がなければ最後の項は 0）。この式は、木の実装の検証の基準になる。

A.4.3 \(\alpha < 1\) のときの即時転換

上限がなく、クーポンがなく、割引率が非負（\(r \ge 0\)、\(s \ge 0\)）の場合を考える。\(\alpha < 1\) で、\(S \ge K_{\min}/\alpha\) のとき、転換価値は \(F/\alpha\) に頭打ちである。転換価値は任意の株価で \(F/\alpha\) 以下だから、将来のどの時点で転換しても、受け取る額は \(F/\alpha\) を超えず、割引すればそれ以下になる。一方、すぐ転換すれば \(F/\alpha\) がそのまま得られる。したがって、アメリカン型の保有者にとって、\(S \ge K_{\min}/\alpha\) では即時転換が最適で、価値は \(F/\alpha\) に等しく、現物への依存がなくなる（デルタもガンマも 0）。

この性質は、同時点の株価を参照する条項そのものの帰結であって、実装の誤りではない。実際の契約は、転換できる日の制限や、参照する株価の定め方で、この性質を抑えていることがある。それは本補論の対象外である。

A.4.4 転換価額を持ち越す型：\((S, K)\) の 2 次元

実際の MSCB は、決まったリセット日 \(\tau_1 < \dots < \tau_n\) に、その日の株価で転換価額を見直し、新しい転換価額を、次のリセット日まで持ち越す。リセットは、その日の転換の前に行う（その日の転換は新しい転換価額を使う）。持ち越す転換価額 \(K\) が状態に加わるので、状態は \((S, K)\) の 2 次元である。

リセットの規則には、二つの型がある。

\[ K^{+} = \begin{cases} \min\bigl(K_{\max},\ \max(K_{\min},\ \alpha S)\bigr) & \text{（上下どちらにも見直す。直前の } K^{-} \text{ によらない）} \\[4pt] \min\bigl(K^{-},\ \max(K_{\min},\ \alpha S)\bigr) & \text{（下げる方向にだけ見直す）} \end{cases} \]

ここで \(K^{-}\) はリセット直前の転換価額、\(K^{+}\) は直後の値である。

2 次元の格子：転換価額の格子の点ごとに、転換比率 \(F/K\) の木（A.3）を持つ。リセットの間は、点どうしが独立にさかのぼる。リセット日には、各現物の節点で、新しい転換価額 \(K^{+}(S, K^{-})\) の位置の値を、\(K\) 軸で補間して引き継ぐ。補間するのは、価値、転換確率、割引率の 3 本である（TF の木の状態）。

補間を \(1/K\) について線形にする理由：転換価値 \(F\,S/K\) は、\(1/K\) について線形である。したがって、価値のうち転換価値の部分は、\(1/K\) について線形に補間すれば誤差が出ない。\(K\) について線形に補間すると、転換価値の部分に、補間だけの誤差が生じる。

A.4.5 限度がないときの \(z = S/K\) への縮約

\(K_{\min} = 0\)（と、上下に見直す型では \(K_{\max} = \infty\)）、つまり転換価額に限度がないとき、この問題は次のように 1 次元に縮約できる。

同次性：償還額 \(F\) とクーポンは、\(S\) にも \(K\) にも依存しない。転換価値 \(F\,S/K\) は \((S, K)\) について 0 次同次である（\(S\) と \(K\) を同じ倍率で変えても変わらない）。リセットの規則も、\(K^{+} \propto S\) または \(K^{+} = \min(K^{-}, \alpha S)\) で、\((S, K)\) を同じ倍率で変えると \(K^{+}\) も同じ倍率で変わる。株価の動きは比例的だから、価値は \[ V(t, S, K) = v(t, z), \qquad z = \frac{S}{K} \] と書ける（0 次同次の関数は、比だけの関数である）。

リセットの写像：限度がなければ、リセットによる \(z\) の変化は、次の写像で書ける。\(z^{-} = S/K^{-}\)、\(z^{+} = S/K^{+}\) として、

  • 下げる方向にだけ見直す型：\(K^{+} = \min(K^{-}, \alpha S)\) より、\(z^{+} = \max(z^{-},\,1/\alpha)\)。
  • 上下に見直す型：\(K^{+} = \alpha S\) より、\(z^{+} = 1/\alpha\)（直前の \(z^{-}\) によらない）。

木の節点の間に \(1/\alpha\) の値が来るときは、\(z\) について線形に補間する。

限度があると縮約できない理由：下限 \(K_{\min}\) や上限 \(K_{\max}\) があると、\(K^{+}\) の規則に絶対的な水準が入り、\((S, K)\) を同じ倍率で変えると規則が変わってしまう。0 次同次性が壊れるので、2 次元の格子を使う。

効果：1 次元の縮約は、2 次元の格子に比べて桁違いに速い。Carmine-Studio の第13章の 13.5 は、同じ条件で、格子の値に縮約が収束することと、速さの違いを、rmql の実測で示している。ただし、ベガなどの感応度を、格子と縮約で比べるときの注意が、補論Bの B.5 にある。

A.5 縮約できない状態と、モンテカルロ法への橋渡し

A.5.1 MBS の元本残高

パススルー型の MBS は、住宅ローンの元本と利息が、投資家にそのまま渡される。月 \(m\) の期限前返済率 SMM は、年率の CPR から \[ \mathrm{SMM}_m = 1 - (1 - \mathrm{CPR}_m)^{1/12} \] で決まる。CPR は、経過月数（シーズニング）と、借換え金利 \(f_m\) の関数である。たとえば \[ \mathrm{CPR}_m = \min\Bigl(\text{上限},\ \mathrm{PSA}\times \min(0.002\,m,\ 0.06)\times \exp\bigl(\beta\,(c - f_m - \text{費用})\bigr)\Bigr) \] （\(c\) は住宅ローン金利、\(\beta\) は借換え金利への感応度）という規則を置く。これは借り手の行動を表す仮定で、最適な行使ではない。

毎月の残高の更新は、元利均等の返済額から、次のように書ける。月初の残高を \(B_{m-1}\)、月利を \(c/12\)、残りの返済月数を \(n - m + 1\) として、 \[ P_m = \frac{B_{m-1}\,c/12}{1 - (1 + c/12)^{-(n - m + 1)}}, \qquad \text{利息} = B_{m-1}\,\frac{c}{12}, \qquad \text{約定元本} = P_m - \text{利息} \] とし、期限前返済は、約定元本を引いたあとの残高に SMM を掛けた額で、 \[ B_m = \bigl(B_{m-1} - \text{約定元本}\bigr)\,\bigl(1 - \mathrm{SMM}_m\bigr) \] となる。

なぜ縮約できないか：今月の返済速度 \(\mathrm{SMM}_m\) が、来月の残高 \(B_m\) を決め、来月の利息と約定元本の割合を決める。残高 \(B_m\) は、借換え金利の過去の全経路 \(f_1, \dots, f_m\) の関数である。これは、価格との比 \(S/K\) のような、水準を打ち消す比では表せない。残高が経路の履歴を覚えている以上、状態は「現在の金利」だけではなく、残高を含む。

A.5.2 TARN の累積クーポンと生存状態

TARN（目標償還つき）は、累積クーポンが目標に達した日に償還される債券である。各クーポン日 \(k\) のクーポンを \(c_k\)（たとえば、為替から作ったレバレッジ型のクーポンを、フロアとキャップで切ったもの）として、累積を \[ A_k = \sum_{j \le k} c_j \] と書く。償還される最初の日 \(\tau = \min\{k : A_k \ge \text{目標}\}\) までの \(c_k\) が支払われ、\(\tau\) で償還される。目標に達した日のクーポンの扱い（その日のクーポンを目標に届く分だけに切る場合と、全額払う場合）は契約の条項である。

状態は、累積 \(A_k\) と、生存の印（\(\tau \ge k\) か）である。クーポンは、各日の為替だけで決まる（状態を持たない）が、支払われるかどうかが、過去のクーポンの和 \(A_{k-1}\) に依存する。この依存は、為替の水準では表せない。同様に、ノックアウト条項（為替が水準を超えた日に償還される）は、生存の印を運ぶ。

A.5.3 モンテカルロ法への橋渡し

状態が価格との比で縮約できず、次元の高い格子も実用的でないとき、経路ごとに状態を持ち越して、経路の平均を取る。\(N\) 本の経路で、各経路 \(i\) の割引キャッシュフローを \(Y^{(i)}\) として、価値の推定は \[ \hat V = \frac{1}{N}\sum_{i=1}^{N} Y^{(i)}, \qquad \mathrm{SE} = \frac{s_Y}{\sqrt N} \] （\(s_Y\) は \(Y^{(i)}\) の標本標準偏差）である。標準誤差は経路数 \(N\) の平方根に反比例して小さくなる。経路ごとに、MBS では残高を 1 か月ずつ、TARN では累積クーポンと生存の印を 1 日ずつ、進める。

MBS の OAS（オプション調整後スプレッド）は、すべての経路の割引率に共通の幅を足し、価値の平均が市場の価格に一致する幅として求める。OAS は、経路の乱数に依存する推定値だから、乱数の種で動き、経路数を増やすと種による散らばりが \(1/\sqrt N\) で小さくなる。

縮約との対比：縮約できる商品（A.1〜A.4）は、1 次元の格子で、誤差を段数の増加で減らせて、計算も速い。縮約できない商品（A.5）は、モンテカルロの統計誤差が残る。ただし、TARN や MBS には、アメリカン型の転換のような、最適行使の判断がない（償還や返済は規則で自動的に起こる）ので、Longstaff–Schwartz 法のような、継続価値の回帰は必要ない。

注意：TARN とノックアウトの条項そのもの（目標に達した日のクーポンの扱い、ノックアウトの観測日の定め）を、独立なシミュレーションと照合する作業は、Carmine-Studio ではまだ行っていない。条項の解釈は、契約ごとに確かめる必要がある。

A.6 この補論のまとめ

  • 縮約の判定は、状態を現物で割った比が、そのまま次の状態として引き継がれるかで決まる。ヨーロピアン、ルックバック、限度のない転換価額の MSCB は、一次同次性か 0 次同次性で比に縮約できる。
  • ルックバックは、監視日に最小値が更新される。更新式 \(w_{\text{前}}(z) = z\,w_{\text{後}}(1)\)（\(z < 1\)）が、比の世界での最小値の更新である。固定ストライクは、変動ストライクの式に定数を足した形に還元できる。
  • 転換社債は TF の枠組みで、価値 \(V\) と転換確率 \(p\) を連動させる。MSCB の転換時リセットは、転換価値を 3 本のコールに分解して、閉じた式にできる。
  • 持ち越し型の MSCB は、\((S, K)\) の 2 次元の格子（\(1/K\) について線形に補間）か、限度がないときの \(z = S/K\) の 1 次元の縮約で解く。
  • MBS の元本残高と TARN の累積クーポンは、比に直せない。経路ごとに状態を持ち越す、モンテカルロ法で評価する。

感応度（グリークス）の求め方と、離散の木での注意点は、補論Bで扱う。数値の実装、条件を動かす画面、照合の記録は、Carmine-Studio の第13章〜第15章と rmql を参照されたい。

# Coral Book『金融工学の応用基礎』

本書は、金融工学の手法を実際の財務・市場データに適用し、その計算を手元のRで再現するための本である。本書の目的は、金融工学を実装し、実際のデータを使って価格評価やリスク計測を再現できるようにすることである。論文で示されたモデルや、個人のExcelで確かめた計算を実務で使うには、データの取得と整形、モデルの実行、結果の検証までを、他の人も同じ手順で繰り返せる形にする必要がある。

いまは、Rをはじめとする無償のオープンソース・ソフトウェアを使い、手元のPCでその計算環境を組み立てられる。高価な専用サーバーや商用のグリッド・ミドルウェアを導入せずに、データ分析、価格評価、リスク計測を一台のPCから始められる。計算量が増えれば、同じ評価関数を活かしながら、複数コアや複数台のPCに処理を広げることもできる。

第I部では、財務・市場データを使った実証分析から、ポートフォリオ最適化、市場・信用リスクの計測、トランシェ評価へ進む。第II部では、無裁定価格理論を基礎に、債券、金利カーブ、OIS、デリバティブの評価を扱う。各章では、モデルの仮定、数式、Rコードを結びつけ、入力や計算条件を変えたときに結果がどう動くかを確かめる。Quartoの各章では、数式とRコードを読みながら計算結果を再現できる。

実装の基盤にはRとtidyverseを用いる。Rは統計解析言語として広く利用されているが、本書では、データハンドリング機能、ベクトル演算、関数型プログラミングの特徴を備えた実装基盤として位置付ける。これらの特徴を活かすことで、金融データの取得・加工から価格評価、リスク計測までを、一貫した設計のもとで実装できる。

金融モデルをサーバー上で実行し、複数の利用者がブラウザから使える形にしたい読者には、姉妹プロジェクトの Carmine Studio『エンタープライズ金融モデル』を勧める。計算エンジンと操作画面を分けた構成や、並列・分散計算、自動微分への展開を扱う。

## 関連するプロジェクト

本書と同じ金融モデルを、別の入口から学ぶプロジェクトがある。

- **Carmine Studio『エンタープライズ金融モデル』**：Reactで条件を操作し、Rサーバー上のRiemannFinMathでモデルを評価するWebアプリ。並列計算、分散計算、自動微分も扱う。
- **Crimson Proof『Leanから見た金融数学』**：金融モデルの仮定をLeanで定義し、どの仮定のもとで何が成り立つかを証明する本。

たとえば無裁定と割引なら、本書の第II部第1章と第3章で割引と複製を計算し、Carmine StudioでOISの気配を変えてスワップの時価を確かめ、Crimson Proofで無裁定に必要な市場の仮定を定義して定理を証明する。

## 描画

```
quarto render          # HTML（_book/）
```

PDF と全体のビルドは `build_all_outputs.ps1`（`build_all_outputs.bat`）です。R の共通関数は `R/utility_LFL.R` にあり、プロジェクトのルートは `_quarto.yml` のあるフォルダとして探します。
